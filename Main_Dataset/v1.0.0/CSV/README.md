# The Alaska Permafrost Thaw Database (Version 1.0.0)

## Outdated version 
This version of the database was the initial release which has since been updated to correct minor errors. Please refer to the most recent version of the database at https://doi.org/10.5281/zenodo.16996415.

## Files Included

This repository contains two primary files associated with **The Alaska Permafrost Thaw Database (Version 1.0.0)**:

1. **`Alaska_Permafrost_Thaw_Database_v1.0.0.csv`**  
   The main dataset containing all abrupt and non-abrupt permafrost thaw locations across Alaska.

2. **`Alaska_Permafrost_Thaw_Database_Topography_v1.0.0.csv`**  
   A companion dataset that includes the same abrupt and non-abrupt permafrost features, supplemented with topographic variables derived from digital elevation data. These include:  
   - **Slope**  
   - **Aspect**  
   - **Elevation**  
   - **Relative elevation**  
   - **Solar radiation index**  

   These variables were used in the analyses presented in the accompanying manuscript.
