# The Alaska Permafrost Thaw Database (Version 1.0.0)

## Geospatial Files Included

This repository contains two geospatial files associated with **The Alaska Permafrost Thaw Database (Version 1.0.0)**:

1. **`Alaska_Permafrost_Thaw_Database_v1.0.0.geojson`**  
   - GeoJSON format of the thaw database (version 1.0.0)  
   - Coordinate Reference System (CRS): WGS84 (EPSG:4326)  

2. **`Alaska_Permafrost_Thaw_Database_Topography_v1.0.0.gpkg`**  
   - GeoPackage format of the thaw database (version 1.0.0)  
   - CRS: WGS84 (EPSG:4326)
